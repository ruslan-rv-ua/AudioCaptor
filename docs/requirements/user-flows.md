# AudioCaptor — Сценарії використання (User Flows)

## UF1: Перший запуск програми

1. Користувач запускає `AudioCaptor.exe`
2. Програма визначає мову системи Windows
3. Якщо мова — українська або російська, інтерфейс відображається українською; інакше — англійською
4. Створюється профіль за замовчуванням (Default)
5. Створюється папка `Recordings` поруч з exe (якщо не існує)
6. Створюється файл `settings.json` поруч з exe
7. Головне вікно відображається в стані "Очікування" (idle)

---

## UF2: Базовий запис з мікрофона

**Передумови:** програма запущена, є хоча б один мікрофон

1. Користувач обирає профіль із режимом виводу "Мікрофон"
2. Користувач обирає мікрофон зі списку пристроїв
3. Користувач натискає гарячу клавішу (коротке натискання)
4. Лунає звуковий сигнал старту
5. Статус змінюється на "Запис"
6. Користувач натискає гарячу клавішу (довге натискання, ≥500мс)
7. Лунає звуковий сигнал зупинки
8. Файл зберігається як `mic_2026-03-28_14-30-00.wav` у папці записів профілю
9. Статус повертається до "Очікування"

---

## UF3: Запис міксу мікрофона та системного звуку

**Передумови:** є мікрофон та пристрій loopback

1. Користувач обирає профіль із режимом виводу "Мікс"
2. Користувач обирає мікрофон та loopback зі списків пристроїв
3. Користувач регулює гучність мікрофона та loopback у профілі (за потреби)
4. Користувач натискає гарячу клавішу — запис починається
5. Аудіо з обох джерел мікшується в реальному часі
6. Користувач зупиняє запис довгим натисканням гарячої клавіші
7. Зберігається один файл з міксом

---

## UF4: Запис з паузою

1. Користувач починає запис (коротке натискання)
2. Під час запису натискає коротко гарячу клавішу — запис призупиняється
3. Лунає сигнал паузи, статус — "Пауза"
4. Аудіодані не записуються у файл
5. Користувач натискає коротко гарячу клавішу — запис відновлюється
6. Запис продовжується з поточного моменту (без заповнення проміжку тишею)
7. Користувач зупиняє запис довгим натисканням

---

## UF5: Керування профілями

### UF5a: Створення нового профілю

1. Користувач відкриває діалог керування профілями
2. Натискає "Додати"
3. Заповнює форму: назва, опис, папка, режим виводу, частота дискретизації, гучність
4. Натискає OK
5. Профіль з'являється у списку та доступний для вибору

### UF5b: Редагування профілю

1. Користувач обирає профіль у списку
2. Натискає "Редагувати" (або подвійний клік)
3. Змінює потрібні параметри
4. Натискає OK — зміни зберігаються

### UF5c: Видалення профілю

1. Користувач обирає профіль у списку
2. Натискає "Видалити"
3. Програма запитує підтвердження
4. Якщо це не останній профіль — профіль видаляється
5. Якщо це останній профіль — програма показує попередження та забороняє видалення

---

## UF6: Зміна гарячої клавіші

1. Користувач відкриває налаштування
2. У секції гарячої клавіші натискає "Захопити клавішу"
3. Натискає бажану комбінацію клавіш (наприклад, Ctrl+F9)
4. Комбінація відображається у полі
5. Користувач натискає OK — нова гаряча клавіша активується негайно

**Альтернативний шлях:** користувач натискає Escape під час захоплення — повернення до попередньої клавіші.

---

## UF7: Зміна мови інтерфейсу

1. Користувач відкриває налаштування
2. Обирає мову зі списку (English / Українська)
3. Програма показує повідомлення: зміна набуде повної дії після перезапуску
4. Після перезапуску інтерфейс відображається обраною мовою

---

## UF8: Відкриття папки з записами

1. Користувач натискає кнопку "Відкрити папку записів"
2. Відкривається Windows Explorer з папкою записів поточного профілю

---

## UF9: Помилка — пристрій не знайдено

1. Користувач намагається почати запис
2. Профіль вимагає мікрофон, але мікрофон не обрано або недоступний
3. Програма показує повідомлення про помилку з вказівкою якого пристрою бракує
4. Запис не починається

---

## UF10: Вихід під час запису

1. Користувач намагається закрити програму під час активного запису
2. Якщо увімкнено "Підтвердження виходу" — з'являється діалог підтвердження
3. Користувач підтверджує — запис зупиняється, файл зберігається, програма закривається
4. Користувач скасовує — програма залишається відкритою, запис продовжується

---

## UF11: Помилка реєстрації гарячої клавіші

1. Програма запускається та намагається зареєструвати глобальну гарячу клавішу
2. Реєстрація не вдається (антивірус блокує, інша програма використовує клавішу, недостатньо прав)
3. Програма показує попередження з можливими причинами
4. Програма продовжує працювати, але без гарячих клавіш
5. Користувач може змінити гарячу клавішу в налаштуваннях та спробувати знову

---

## UF12: Помилка під час запису (пристрій відключено)

1. Запис активний
2. Аудіопристрій відключається або стає недоступним
3. Програма зупиняє запис
4. Зберігає те, що було записано до моменту помилки
5. Показує повідомлення про помилку із зазначенням операції та деталей
6. Статус повертається до "Очікування"

---

## UF13: Конфлікт імен профілів

1. Користувач створює новий профіль
2. Вводить ім'я, яке вже існує
3. Програма показує повідомлення про помилку: ім'я має бути унікальним
4. Користувач змінює ім'я та зберігає успішно

---

## UF14: Папка записів недоступна

1. Користувач починає запис
2. Папка записів профілю не існує або недоступна для запису
3. Програма показує повідомлення про помилку
4. Запис не починається

---

## UF15: Оновлення через Scoop

1. Користувач виконує `scoop update audiocaptor`
2. Scoop завантажує нову версію exe
3. Файли `settings.json`, папка `Recordings` та файл логу зберігаються завдяки механізму persist
4. Після запуску нової версії всі налаштування та записи на місці
