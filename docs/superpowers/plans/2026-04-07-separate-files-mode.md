# SeparateFiles Recording Mode — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `SeparateFiles` output mode that records microphone and loopback to two separate WAV files simultaneously, without mixing.

**Architecture:** `SeparateFiles` is added as a new variant of the `OutputMode` enum (Rust + TypeScript). The mixer loop treats it identically to Mix modes for synchronization (both sources drain together), but writes mic-only to the primary writer and loopback-only to the secondary writer. The existing `secondary_writer` finalization path in the mixer already handles cleanup on stop.

**Tech Stack:** Rust (serde, hound, ringbuf, rubato), Tauri v2, Svelte 5, TypeScript, Paraglide JS (i18n auto-generated from messages/*.json via Vite plugin)

**Spec:** `docs/superpowers/specs/2026-04-07-separate-files-mode-design.md`

Tasks 1, 2, and 3 must all be completed back-to-back before running `cargo build`. The first successful build check is in Task 3, Step 6.

```rust
            OutputMode::MixPlusLoopback => {
                let mix = mix_samples(&mic_processed, &loop_processed, mic_volume, loopback_volume, target_channels);
                let loop_only: Vec<f32> = loop_processed.iter()
                    .map(|&s| (s * loopback_volume).clamp(-1.0, 1.0)).collect();
                if !loop_only.is_empty() {
                    if let Some(ref mut sw) = config.secondary_writer {
                        if let Err(e) = sw.write_samples(&loop_only) {
                            log::error!("Secondary WAV write error: {}", e);
                        }
                    }
                }
                mix
            }
            OutputMode::SeparateFiles => {
                // Write loopback to secondary writer
                let loop_only: Vec<f32> = loop_processed.iter()
                    .map(|&s| (s * loopback_volume).clamp(-1.0, 1.0))
                    .collect();
                if !loop_only.is_empty() {
                    if let Some(ref mut sw) = config.secondary_writer {
                        if let Err(e) = sw.write_samples(&loop_only) {
                            log::error!("Secondary WAV write error: {}", e);
                        }
                    }
                }
                // Return mic samples for primary writer
                mic_processed.iter()
                    .map(|&s| (s * mic_volume).clamp(-1.0, 1.0))
                    .collect()
            }
        };
```
