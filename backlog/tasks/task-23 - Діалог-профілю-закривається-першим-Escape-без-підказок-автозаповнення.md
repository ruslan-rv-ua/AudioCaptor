## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Знайшла перевірка з клавіатури під час TASK-15 (2026-11-24, тестова копія з NVDA, англійський інтерфейс).

Коли профіль зберегли клавішею Enter у полі Name, WebView2 запам'ятовує введену назву як підказку автозаповнення браузера. Наступного разу в порожньому полі Name діалогу «New Profile» NVDA каже «містить автоматичне заповнення», а перший Escape лише ховає підказки (NVDA: «Пропозиції, приховані для цього сеансу»); діалог закривається тільки другим Escape. Підказки лежать у даних WebView2 (`EBWebView`), тож лишаються й після перезапуску програми. Тест `just smoke` цього не бачить: його копія щоразу починає з порожніми даними WebView2.
<!-- SECTION:DESCRIPTION:END -->
