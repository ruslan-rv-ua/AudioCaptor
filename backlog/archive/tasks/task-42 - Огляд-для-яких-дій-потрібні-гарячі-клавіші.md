## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Власник хоче знати, чи кожна дія в програмі має гарячу клавішу, і для яких дій її варто додати. Програмою користуються передусім люди з NVDA, які записують зустрічі й лекції, тож швидкий доступ з клавіатури важливий. Огляд охоплює головне вікно, діалоги профілю, налаштувань і «Про програму», підтвердження виходу й видалення, меню трея, глобальну гарячу клавішу запису, а також клавіші браузера, які WebView2 ще пропускає. Код не змінюється: результат — таблиця дій, рекомендація, вибір власника, нова задача на прийняті клавіші й чернетки для знахідок.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### 1. Перелік дій і як до них дістатися сьогодні

Порядок Tab у головному вікні: ⊟ (у трей), ⓘ (Про програму), ⚙ (Налаштування), список профілів, +, ✎, ✕, мікрофон, системний звук, гучність мікрофона, гучність системного звуку, кнопки запису. Після запуску фокус на списку профілів.

| Місце | Дія | Сьогодні |
|---|---|---|
| Вікно | Почати запис | Alt+S (коли пристрої вибрано; інакше мовчить — TASK-38), кнопка |
| Вікно | Пауза / Продовжити / Зупинити | Alt+P / Alt+R / Alt+T, кнопки |
| Вікно | Почути стан (і конвертацію) | Alt+I |
| Вікно | Згорнути в трей | Escape, кнопка ⊟ |
| Вікно | Про програму | F1 (також поверх діалогів), кнопка ⓘ, меню трея |
| Вікно | Налаштування | лише Tab (кнопка ⚙) |
| Вікно | Вибрати профіль | лише Tab + стрілки (фокус там після запуску) |
| Вікно | Створити / змінити / видалити профіль | лише Tab |
| Вікно | Мікрофон, системний звук | лише Tab + стрілки |
| Вікно | Гучність (2 повзунки) | лише Tab + стрілки |
| Вікно | Відкрити папку записів | **немає у вікні**, лише меню трея |
| Вікно | Вийти | Alt+F4 (обробник у `handleMnemonic`), кнопка закриття, «Вийти» в треї |
| Діалог профілю | Зберегти / створити | Enter у текстовому полі (форма), кнопка |
| Діалог профілю | Скасувати | Escape, кнопка |
| Діалог профілю | Огляд теки, поля | лише Tab |
| Налаштування | Закрити | Enter або Escape (Escape під час захоплення клавіші скасовує захоплення) |
| Налаштування | Тема, захопити / очистити клавішу, прапорці, мова | лише Tab |
| Про програму | Закрити | Enter, Escape |
| Підтвердження виходу / видалення | Скасувати / підтвердити | фокус на «Скасувати»; Escape скасовує; Enter натискає кнопку з фокусом; Tab між двома |
| Меню трея | Показати/сховати, Старт/Пауза/Продовжити, Зупинити, Відкрити папку, Про програму, Вийти | стрілки й Enter; літер-мнемонік немає; до трея — Win+B |
| Глобально | Запис | Pause за замовчуванням (змінюється в налаштуваннях): коротко — старт/пауза/продовження, довго ≥ 0,5 с — стоп |
| Глобально | Показати вікно | клавіші немає; трей або повторний запуск exe (single-instance показує вікно) |
| Глобально | Почути стан | немає (лише звуки змін стану) |

Помітки:
- Alt+S/P/R/T/I діють і тоді, коли відкрито діалог: слухач стоїть на всьому вікні, а діалоги перехоплюють лише Escape (і Enter). Шкоди не видно, тож задачі не створено.
- F1 і Alt+F4 ніде не описано: ні в «Про програму», ні в README, ні в DEVELOPMENT.md (там лише Alt-комбінації).

### 2. Клавіші браузера у WebView2 (збірка для користувачів)

- Tauri 2.12 не викликає `with_browser_accelerator_keys` і `with_default_context_menus`, а у wry обидва `true` за замовчуванням. Отже, у вікні працюють: F5, Shift+F5, Ctrl+R, Ctrl+Shift+R (перезавантаження), Ctrl+P (друк), Ctrl+F, F3, Ctrl+G (пошук), а також меню браузера з клавіші меню, Shift+F10 чи правого кліку («Назад», «Оновити», «Зберегти як», «Друк»).
- Шкода: перезавантаження скидає вікно, губить незбережений діалог профілю й переносить фокус. Під час запису стан відновлюється з наступного тіку, але ефект оголошень бачить перехід «невідомо → Recording» і NVDA хибно каже «запис почато». Друк і пошук відкривають чужі для програми вікна та панелі.
- Масштаб (Ctrl+плюс/мінус/0, Ctrl+коліщатко) вимкнено: `zoomHotkeysEnabled` у Tauri за замовчуванням `false`.
- Інструменти розробника (F12, Ctrl+Shift+I) лише в debug-збірці (`just dev`), бо features `devtools` не ввімкнено.
- Живцем не перевіряли: F7 (переміщення кареткою), Ctrl+N і Ctrl+S у WebView2 — критерії TASK-43 це покривають.

### 3. Рекомендація, яку отримав власник

| Дія | Сьогодні | Пропозиція | Рекомендовано |
|---|---|---|---|
| Відкрити папку записів | лише трей | кнопка у вікні + Alt+O | так |
| Клавіші й меню браузера | працюють | вимкнути | так |
| Довідка | F1, Alt+F4 не описано | дописати; пояснити «Сполучення клавіш» ярлика Windows для показу вікна | так |
| Профілі | лише Tab | Ctrl+N, F2, Delete | за бажанням |
| Меню трея | без літер | підкреслені літери | за бажанням, спершу перевірити з NVDA |
| Налаштування | лише Tab | Ctrl+кома | за бажанням |
| Пристрої, гучність | Tab + стрілки | нічого | — |
| Стан, коли вікно сховане | лише звуки | глобальна «сказати стан» — чернеткою | окреме рішення |

Перевірка конфліктів: Alt+O, Ctrl+N, F2, Delete, Ctrl+кома не зайняті NVDA (у режимі `role="application"` NVDA пропускає їх програмі), Windows у вікні без меню їх не використовує; Ctrl+N у WebView2 треба перевірити (критерій #3 TASK-43). Літера Alt-мнемоніки однакова в обох мовах, як у наявних.

### 4. Вибір власника

Прийняв усе запропоноване: Alt+O з кнопкою, Ctrl+N/F2/Delete для профілів, літери в меню трея, Ctrl+кома, вимкнення клавіш і меню браузера, доповнення довідки. Не брали лише «нічого» для пристроїв і гучності — це рекомендація залишити як є.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Огляд за кодом (без запуску з NVDA). Запис і стан мають клавіші (Alt+S/P/R/T/I, глобальна Pause), «Про програму» — F1, згортання — Escape, вихід — Alt+F4. Решта дій вікна — лише Tab; «Відкрити папку записів» є тільки в меню трея; меню трея без літер. F1 і Alt+F4 не описано в довідці.

Власник прийняв усе запропоноване: Alt+O з кнопкою папки, Ctrl+N/F2/Delete для профілів, літери в меню трея, Ctrl+кома, вимкнення клавіш і меню браузера, доповнення довідки. Це TASK-43 (без віхи). Ідея почути стан, коли вікно сховане, — DRAFT-20.
