# Етапи розробки AudioCaptor

## Етапи

### [Етап 1 — MVP: Базовий запис аудіо](phase-1.md)

Ініціалізація проекту Tauri + Svelte 5, захоплення аудіо з мікрофона та loopback через WASAPI, мікшування в реальному часі, керування записом через UI, збереження у WAV, базова доступність для скрін-рідерів.

### [Етап 2 — Глобальні гарячі клавіші та звукові сповіщення](phase-2.md)

Глобальна гаряча клавіша з FSM розрізненням короткого/довгого натискання, звукові сповіщення (старт/пауза/стоп) через rodio, мнемоніки, валідація пристроїв перед записом.

### [Етап 3 — Профілі запису та розширені режими виводу](phase-3.md)

CRUD профілів запису з валідацією, режими Мікс+Мікрофон та Мікс+Loopback з паралельним записом у декілька WAV-файлів, кастомні імена файлів, динамічне оновлення списку пристроїв.

### [Етап 4 — Інтернаціоналізація, налаштування та Scoop](phase-4.md)

Paraglide JS i18n (en + uk), повна сторінка налаштувань з persistence, aria-live регіони для анонсів стану, Scoop-маніфест з persist.
