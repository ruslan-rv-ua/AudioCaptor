# AudioCaptor — Вимоги до продукту (PRD)

## 1. Огляд продукту

**Назва:** AudioCaptor

**Призначення:** Програма для запису аудіо з мікрофона та системного звуку (loopback) з можливістю одночасного запису обох джерел, мікшування в реальному часі та керування через глобальні гарячі клавіші.

**Цільова аудиторія:**
- Користувачі, яким потрібен зручний запис системного звуку та/або мікрофона
- Подкастери, стрімери, викладачі, що записують екранні уроки
- Користувачі з порушеннями зору, які працюють із зчитувачами екрану

**Ліцензія:** MIT

## 2. Обов'язкові умови

| # | Умова | Деталі |
|---|---|---|
| OC-1 | Windows only | Програма працює виключно на Windows |
| OC-2 | Портативність | Один виконуваний файл (.exe), не потребує встановлення |
| OC-3 | Дані поруч з exe | Налаштування, логи та записи за замовчуванням зберігаються відносно розташування exe-файлу |
| OC-4 | Scoop | Підтримка встановлення та оновлення через пакетний менеджер Scoop |
| OC-5 | Scoop persist | При оновленні через Scoop налаштування та записи користувача зберігаються (механізм persist) |
| OC-6 | Доступність | Повна підтримка зчитувачів екрану (screen readers) — обов'язкова вимога найвищого пріоритету |

## 3. Функціональні вимоги

| # | Вимога |
|---|---|

| FR1.2 | Запис системного звуку (loopback) |

### FR2: Мікшування в реальному часі

| # | Вимога |
|---|---|
| FR2.1 | Об'єднання аудіопотоків мікрофона та loopback в один мікс під час запису |

### FR3: Керування записом

| # | Вимога |
|---|---|

## 5. Обмеження та зауваження

- **Заборона російської мови** — додавання локалі `ru` заборонено на рівні вимог проекту
- **Розширюваність форматів** — поточна версія підтримує лише WAV, але архітектура повинна дозволяти додавання інших форматів (MP3, OGG тощо) у майбутніх версіях
- **Scoop persist** — при оновленні через Scoop зберігаються: `settings.json`, папка `Recordings/`, файл логу
- **Вимоги не фіксують**: конкретний стек технологій, мову програмування, GUI-фреймворк, аудіо API, спосіб збірки в exe, наявність чи відсутність кнопок керування записом у GUI (на розсуд розробника)
