## 2. P2-003: Версіонування settings.json

**Мета:** переконатися що `version` поле з'являється в файлі і міграція працює.

### 2.1 Новий settings.json

- [ ] Запустити додаток (перший запуск після видалення settings.json)
- [ ] Змінити будь-яке налаштування (наприклад, гучність)
- [ ] Закрити додаток
- [ ] Відкрити `settings.json` у текстовому редакторі
- [ ] Перевірити що є поле `"version": 1`
- [ ] Перевірити що `"outputMode"` має значення `"Mix"` (PascalCase, не "mix")

### 2.2 Міграція старого файлу (необов'язково)

- [ ] Вручну створити `settings.json` без поля `version`:
  ```json
  {
    "selectedMic": null,
    "selectedLoopback": null,
    "micVolume": 1.0,
    "loopbackVolume": 0.5,
    "outputMode": "Mix",
    "sampleRate": 48000,
    "hotkey": "Pause",
    "soundEnabled": true
  }
  ```
- [ ] Запустити додаток
- [ ] Після першого збереження налаштувань перевірити що `"version": 1` додалось

## 3. P1-006: Типізований OutputMode

**Мета:** переконатися що вибір режиму виводу коректно зберігається і відновлюється.

- [ ] Запустити додаток

- [ ] Встановити режим **Loopback** → закрити → відкрити → режим має залишитись **Loopback**
- [ ] Встановити режим **Mix** → закрити → відкрити → режим має залишитись **Mix**
- [ ] Відкрити `settings.json`: `"outputMode"` має бути `"Microphone"` / `"Loopback"` / `"Mix"` (PascalCase)

## 4. P0-002: Закриття вікна під час запису

**Мета:** WAV файл не повинен пошкоджуватись при закритті вікна під час активного запису.

### 4.1 Базовий тест

- [ ] Почати запис (натиснути Start)
- [ ] Зачекати 3–5 секунд
- [ ] Закрити вікно через кнопку X (не через Stop)
- [ ] Знайти новий WAV файл у папці `Recordings/`
- [ ] Відкрити файл в аудіоплеєрі
- [ ] Файл відтворюється коректно (не пошкоджений, не порожній)
- [ ] Тривалість файлу відповідає приблизно часу запису

### 4.2 Тест під час паузи

- [ ] Почати запис → поставити на паузу → закрити вікно
- [ ] WAV файл коректно відтворюється

### 4.3 Перевірка логів

- [ ] Відкрити `logs/audiocaptor.log`
- [ ] Знайти рядок: `Window closing during recording — stopping recording`
- [ ] Знайти рядок: `WAV file finalized:`

## 5. Режими запису (регресія після рефакторингу mixer.rs)

**Мета:** переконатися що convert_channels рефакторинг не порушив аудіо.

### 5.1 Режим Мікрофон

- [ ] Вибрати режим **Мікрофон**, вибрати мікрофон
- [ ] Записати 5–10 секунд голосу
- [ ] Зупинити, відтворити WAV
- [ ] Звук чистий, стерео (або моно в залежності від мікрофона), без артефактів

### 5.2 Режим Loopback

- [ ] Вибрати режим **Loopback**, вибрати loopback пристрій
- [ ] Відтворити будь-яку музику/відео на комп'ютері
- [ ] Записати 5–10 секунд
- [ ] Зупинити, відтворити WAV
- [ ] Запис відповідає відтвореному звуку, без артефактів

### 5.3 Режим Mix

- [ ] Вибрати режим **Mix**, вибрати обидва пристрої
- [ ] Говорити в мікрофон, одночасно відтворювати музику
- [ ] Записати 5–10 секунд
- [ ] Зупинити, відтворити WAV
- [ ] Обидва джерела чутні в записі, без десинхронізації

### 5.4 Перевірка з різними sample rates

- [ ] Спробувати Mix режим з `sampleRate: 44100` (не за замовчуванням)
- [ ] WAV файл коректний, тривалість вірна

## 6. Пауза і відновлення

**Мета:** перевірити що рефакторинг не вплинув на логіку паузи.

- [ ] Почати запис (режим Mix або Loopback)
- [ ] Зачекати 5 секунд → поставити на паузу
- [ ] Зачекати 3 секунди (цей час НЕ має входити в запис)
- [ ] Відновити → записати ще 5 секунд → зупинити
- [ ] Відтворити WAV: тривалість має бути ~10 секунд (5 + 5, без 3 секунд паузи)
- [ ] Немає "провалу" тиші або артефактів у місці відновлення

## 7. Хоткей (регресія після змін hotkey.rs)

**Мета:** переконатися що зміни у hotkey.rs (OutputMode import) не зламали логіку.

- [ ] Налаштувати хоткей (наприклад, `Ctrl+Alt+R`)
- [ ] Short press (< 0.5 сек): запускає запис
- [ ] Short press ще раз: ставить на паузу
- [ ] Short press ще раз: відновлює
- [ ] Long press (≥ 0.5 сек): зупиняє запис
- [ ] WAV файл збережено

### Перевірка device validation у хоткеї

- [ ] Вибрати режим **Mix** але НЕ вибирати loopback пристрій
- [ ] Натиснути хоткей
- [ ] Звук попередження (якщо `soundEnabled: true`) або тихо ігнорується
- [ ] Запис НЕ починається
