# Етап 4 — Інтернаціоналізація, налаштування та Scoop

## Мета

Локалізація UI (англійська + українська), повна сторінка налаштувань, aria-live регіони для доступності, підтримка Scoop.

---

## Функціональність

### 1. Інтернаціоналізація (FR7.1–FR7.6)

- Встановити Paraglide JS 2.0 з Vite plugin (`@inlang/paraglide-js/vite`)
- Створити файли повідомлень:
  - `messages/en.json` — англійська (fallback)
  - `messages/uk.json` — українська
  - **Без** `ru.json` — заборонено вимогами
- Замінити всі хардкодовані рядки UI на виклики типізованих функцій Paraglide: `m.recording_started()`
- Автодетекція мови системи при першому запуску:
  - `navigator.language` → якщо `uk` або `ru` → українська, інакше → англійська
  - Збереження вибору в `settings.json`
- Зміна мови через налаштування → набуває дії після перезапуску (FR7.4)
- Rust backend повертає структуровані коди помилок (`"error.device_lost"`, `"state.recording"`), фронтенд маппить їх у локалізовані рядки — жодного дублювання перекладів
- Якщо системна мова `ru` → fallback на `uk`

### 2. Повна сторінка налаштувань (FR6.1–FR6.7)

- Окрема сторінка/панель налаштувань з розділами:

  **Гаряча клавіша:**
  - Відображення поточної комбінації
  - Кнопка "Захопити нову" → режим захоплення: спочатку зняти глобальний шоткат (`unregister_hotkey`), фронтенд слухає натискання, потім реєструє новий шоткат (`set_hotkey`)
  - Кнопка "Скинути до Pause/Break" (FR6.2)
  - IPC-команди: `set_hotkey` (вже існує), `unregister_hotkey` (тимчасове зняття під час захоплення, щоб глобальний шоткат не спрацьовував)

  **Звук:**
  - Перемикач увімкнення/вимкнення звукових сповіщень (FR6.3)

  **Підтвердження виходу:**
  - Перемикач підтвердження виходу під час активного запису (FR6.4)
  - При увімкненні: спроба закрити вікно під час запису → діалог підтвердження

  **Мова:**
  - Вибір мови: English / Українська (FR6.5)
  - Після зміни — повідомлення "зміна набуде дії після перезапуску"

- Автоматичне збереження всіх налаштувань у `settings.json` при змінах (FR6.7)
- IPC-команди: `get_settings`, `save_settings`
- Структура `settings.json`:
  ```json
  {
    "selected_mic": null,
    "selected_loopback": null,
    "hotkey": "Pause",
    "sound_enabled": true,
    "confirm_exit_during_recording": true,
    "language": "en",
    "profiles": [...],
    "active_profile_id": "..."
  }
  ```

### 3. aria-live регіони (FR8.6)

- Додати `<div role="status" aria-atomic="true">` для анонсів стану запису (`role="status"` має неявне `aria-live="polite"`)
- При зміні стану оновлювати текст: "Recording started" / "Recording paused" / "Recording stopped"
- Текст локалізований через Paraglide
- Скрін-рідер автоматично озвучує зміни без взаємодії користувача
- Дублює інформацію звукових сповіщень для випадку коли звуки вимкнені

### 4. Scoop (OC-4, OC-5)

- Створити Scoop-маніфест `audiocaptor.json`:
  ```json
  {
    "version": "1.0.0",
    "description": "AudioCaptor — portable audio recording application",
    "homepage": "https://github.com/...",
    "license": "MIT",
    "url": "https://github.com/.../releases/download/v$version/AudioCaptor.exe",
    "hash": "",
    "bin": "AudioCaptor.exe",
    "persist": ["settings.json", "logs", "Recordings"],
    "checkver": { "github": "https://github.com/..." }
  }
  ```
- `persist` забезпечує збереження налаштувань, логів та записів при оновленні через Scoop (OC-5)
- Перевірити, що шляхи в Rust коректно працюють у директорії Scoop (`~/scoop/apps/audiocaptor/current/`)
- Документувати встановлення: `scoop bucket add <bucket>` → `scoop install audiocaptor`

## Технічні вимоги та обмеження

| Вимога | Деталі |
|--------|--------|
| Paraglide | Vite plugin, не залежить від SvelteKit — працює з plain Svelte |
| Перезапуск | Зміна мови не потребує перезавантаження сторінки — достатньо перезапуску exe |
| Scoop persist | Симлінки: Scoop створює junction points для persist-папок — перевірити що `std::env::current_exe()` резолвить правильний шлях через junction |
| Розмір перекладів | Paraglide — compiled output, tree-shakeable — невикористані рядки не потрапляють у бандл |

- [ ] UI відображається українською при виборі мови "Українська"
- [ ] Усі рядки UI локалізовані (жодного хардкодованого тексту)
- [ ] При першому запуску мова визначається автоматично за системою
- [ ] Якщо системна мова `ru` — fallback на українську (FR7.7)
- [ ] Зміна мови зберігається в `settings.json` та діє після перезапуску
- [ ] Сторінка налаштувань містить усі розділи: гаряча клавіша, звук, підтвердження виходу, мова
- [ ] Захоплення нової гарячої клавіші працює через UI
- [ ] Скидання гарячої клавіші до Pause/Break працює
- [ ] Перемикач звукових сповіщень працює
- [ ] Підтвердження виходу під час запису працює (при увімкненні)
- [ ] Усі налаштування зберігаються автоматично
- [ ] aria-live регіон озвучує зміну стану запису скрін-рідером
- [ ] Текст aria-live регіону локалізований
- [ ] Scoop-маніфест створений та валідний
- [ ] `scoop install` + `scoop update` зберігає `settings.json`, `logs/`, `Recordings/`
- [ ] Програма коректно працює з директорії Scoop
- [ ] Сторінка налаштувань повністю доступна через клавіатуру та скрін-рідер
