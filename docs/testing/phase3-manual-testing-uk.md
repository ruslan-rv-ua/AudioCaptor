## 1. Перший запуск і міграція налаштувань

### 1.1 Чистий перший запуск (без попереднього `settings.json`)

- [x] Видали файл `settings.json` поруч з exe (якщо існує)
- [x] Запусти застосунок
- [x] У селекторі профілів відображається **"Default"** профіль
- [ ] Відкрий `settings.json` і переконайся що:
  - поле `"version"` дорівнює `2`
  - є масив `"profiles"` з одним елементом
  - є поле `"activeProfileId"`
  - профіль Default містить: `outputFolder`, `outputMode`, `sampleRate`, `micVolume`, `loopbackVolume`, `micFilename`, `loopbackFilename`, `mixFilename`

### 1.2 Міграція з v1 (старий плаский формат)

- [ ] Зупини застосунок
- [ ] Заміни `settings.json` на v1-файл такого вигляду:
  ```json
  {
    "version": 1,
    "selectedMic": null,
    "selectedLoopback": null,
    "micVolume": 0.8,
    "loopbackVolume": 0.3,
    "outputMode": "Mix",
    "sampleRate": 44100,
    "hotkey": "Pause",
    "soundEnabled": true
  }
  ```
- [ ] Запусти застосунок
- [ ] Відкрий `settings.json` — `"version"` має бути `2`
- [ ] У профілі Default: `micVolume` = 0.8, `loopbackVolume` = 0.3, `sampleRate` = 44100, `outputMode` = "Mix"

### 1.3 Міграція з v0 (зовсім старий формат без `version`)

- [ ] Заміни `settings.json` на:
  ```json
  {
    "selectedMic": null,
    "selectedLoopback": null,
    "hotkey": "Pause",
    "soundEnabled": true
  }
  ```
- [ ] Запусти застосунок — `"version"` має стати `2` без помилок

## 2. CRUD профілів

### 2.1 Створення профілю

- [ ] Натисни **`+`** поруч з селектором профілів
- [ ] Відкривається діалог **"New Profile"**
- [ ] Заповни поля:
  - Назва: `Podcast`
  - Опис: `Запис подкасту`
  - Папка виводу: `Recordings\Podcast`
  - Режим виводу: `Mix (Mic + System)`
  - Sample Rate: `48000 Hz`
  - Mic Volume: `1.2`
  - Loopback Volume: `0.4`
  - Mic Filename: `podcast-mic`
  - Loopback Filename: `podcast-loop`
  - Mix Filename: `podcast-mix`
- [ ] Натисни **"Create"**
- [ ] Профіль `Podcast` з'явився у дропдауні
- [ ] Профіль `Podcast` обраний як активний

### 2.2 Валідація назви профілю

- [ ] Натисни **`+`**, залиш поле **Name** порожнім, натисни "Create"
- [ ] З'являється повідомлення про помилку: *"Profile name is required"*
- [ ] Діалог **не закривається**

### 2.3 Валідація імен файлів

- [ ] Натисни **`+`**, введи назву `Test`, у **Mix Filename** введи `mix/bad`
- [ ] Натисни "Create" — помилка про заборонені символи
- [ ] Очисти поле Mix Filename — те саме повідомлення: `Filenames must not be empty or contain < > : " / \ | ? *`
- [ ] Введи `mix` — можна зберегти

### 2.4 Редагування профілю

- [ ] Обери профіль `Podcast` у дропдауні
- [ ] Натисни **✎** (Edit)
- [ ] Відкривається діалог **"Edit Profile"** з поточними значеннями
- [ ] Зміни назву на `Podcast v2`
- [ ] Натисни **"Save"**
- [ ] У дропдауні відображається `Podcast v2`
- [ ] Налаштування в застосунку оновились (гучність, режим)

### 2.5 Перемикання профілів

- [ ] Переключись на **"Default"** у дропдауні
- [ ] Повзунки гучності і режим виводу оновились до значень профілю Default
- [ ] Переключись назад на `Podcast v2` — значення знову змінились

### 2.6 Видалення профілю

- [ ] Обери `Podcast v2` у дропдауні
- [ ] Натисни **✕** (Delete)
- [ ] З'являється підтвердження `"Delete this profile?"`
- [ ] Натисни **OK**
- [ ] `Podcast v2` зник з дропдауну
- [ ] Автоматично обраний інший профіль (наприклад, Default)

### 2.7 Неможливо видалити останній профіль

- [ ] Залиш лише один профіль у списку
- [ ] Кнопка **✕** задізейблена (сіра, не можна натиснути)

### 2.8 Закриття діалогу через Escape

- [ ] Відкрий діалог (+ або ✎)
- [ ] Натисни **Escape** — діалог закривається без збереження

### 2.9 Фокус-трапінг у діалозі

- [ ] Відкрий діалог
- [ ] Натискай **Tab** — фокус циклічно переходить між елементами діалогу, **не виходить** за його межі
- [ ] Натискай **Shift+Tab** — фокус іде у зворотньому напрямку в межах діалогу

## 3. Запис у нових режимах

> **Передумова:** обрано мікрофон і loopback-пристрій.

### 3.1 Режим `Mix + Microphone (2 files)`

- [ ] Відредагуй активний профіль: встанови режим **"Mix + Microphone (2 files)"**
- [ ] Переконайся що поля `Mix Filename` = `mix`, `Mic Filename` = `mic`
- [ ] Запусти запис, зроби кілька секунд звуку, зупини
- [ ] У папці профілю (`output_folder`) є **два** файли:
  - `mix_YYYY-MM-DD_HH-MM-SS.wav` — мікс
  - `mic_YYYY-MM-DD_HH-MM-SS.wav` — тільки мікрофон
- [ ] Відтвори обидва файли — у `mix` чути і мікрофон і системний звук, у `mic` — тільки мікрофон

### 3.2 Режим `Mix + System audio (2 files)`

- [ ] Встанови режим **"Mix + System audio (2 files)"**
- [ ] Поля: `Mix Filename` = `mix`, `Loopback Filename` = `loopback`
- [ ] Запусти і зупини запис
- [ ] У папці **два** файли:
  - `mix_*.wav` — мікс
  - `loopback_*.wav` — тільки системний звук
- [ ] `loopback_*.wav` не містить звуку мікрофону

### 3.3 Стандартний режим `Mix` (регресія)

- [ ] Встанови режим **"Mix (Mic + System)"**
- [ ] Запусти і зупини запис
- [ ] Створено **один** файл `mix_*.wav`

### 3.4 Режим `Microphone only` (регресія)

- [ ] Встанови режим **"Microphone only"**
- [ ] Запусти і зупини запис
- [ ] Один файл `mic_*.wav` з звуком мікрофону

### 3.5 Режим `System audio only` (регресія)

- [ ] Встанови режим **"System audio only"**
- [ ] Запусти і зупини запис
- [ ] Один файл `loopback_*.wav` з системним звуком

### 3.6 Кастомні імена файлів

- [ ] Відредагуй профіль: `Mix Filename` = `my-recording`, `Mic Filename` = `my-mic`
- [ ] Запис у режимі MixPlusMicrophone — файли мають назви `my-recording_*.wav` і `my-mic_*.wav`

### 3.7 Кастомна папка виводу

- [ ] Встанови `Output Folder` = `MyPodcast\Session1`
- [ ] Зроби запис — папка `MyPodcast\Session1` створена автоматично поруч з exe
- [ ] Файли знаходяться всередині цієї папки

## 5. Детектор підключення/відключення пристроїв

> Потрібен фізичний аудіо-пристрій (мікрофон або навушники з мікрофоном).

### 5.1 Автоматичне оновлення списку пристроїв

- [ ] Запусти застосунок, список пристроїв заповнений
- [ ] **Підключи** USB-мікрофон або навушники
- [ ] Список пристроїв **автоматично** оновився (без перезапуску)
- [ ] **Відключи** пристрій → він зник зі списку автоматично

### 5.2 DEVICE_LOST — відключення під час запису

- [ ] Обери мікрофон і запусти запис
- [ ] Під час запису **відключи** мікрофон
- [ ] Запис **автоматично зупиняється**
- [ ] З'являється повідомлення про помилку: **"DEVICE_LOST: Active audio device was disconnected"** (або аналогічне)
- [ ] WAV-файл зберігається (не пошкоджений, хоча і коротший)

## 8. Граничні випадки

- [ ] Створи 10+ профілів — дропдаун прокручується, все працює
- [ ] Профіль з назвою у 100 символів — зберігається і відображається
- [ ] Профіль з описом порожнім — зберігається без помилок
- [ ] Два профілі з однаковою назвою — система дозволяє (id різні), обидва у списку
- [ ] Стартуй застосунок без підключеного жодного аудіо-пристрою — не крашиться, показує порожній список
