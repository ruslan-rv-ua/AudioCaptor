# Етап 2 — Глобальні гарячі клавіші та звукові сповіщення

## Мета

Керування записом з будь-якого вікна Windows через глобальну гарячу клавішу зі звуковим зворотним зв'язком.

---

## Функціональність

### 1. Глобальна гаряча клавіша (FR3.7–FR3.12)

- Реєстрація глобальної гарячої клавіші через `tauri-plugin-global-shortcut`
- Клавіша за замовчуванням: Pause/Break (VK_PAUSE)
- Підтримка модифікаторів: Ctrl, Alt, Shift
- FSM розрізнення короткого/довгого натискання:
  - `Pressed` → зберегти `press_timestamp`
  - `Released` → обчислити `duration = now - press_timestamp`:
    - Стан IDLE: будь-яка тривалість → START
    - Стан RECORDING: `< 500мс` → PAUSE, `≥ 500мс` → STOP
    - Стан PAUSED: `< 500мс` → RESUME, `≥ 500мс` → STOP
- Збереження обраної комбінації клавіш у `settings.json`
- Перереєстрація при зміні комбінації без перезапуску

### 2. Звукові сповіщення (FR9.1–FR9.5)

- Три розрізнювані звуки: старт запису, пауза, зупинка
- Формат: OGG, вбудовані у бінарний файл через `include_bytes!()`
- Відтворення через `rodio`: `Decoder::new(Cursor::new(data))` → `Sink::append()`
- Звук відтворюється після кожної зміни стану запису (як через UI, так і через гарячу клавішу)
- Налаштування: увімкнення/вимкнення у `settings.json` (FR6.3)
- При вимкненні — звуки не відтворюються, без помилок

### 3. Мнемоніки (FR8.3)

- Гарячі літери для основних елементів керування (Alt+літера)
- Підкреслення літер-мнемонік у label при натиснутому Alt
- Реалізація через кастомну систему `keydown` обробників (не `accesskey` — Svelte попереджає про конфлікти)

### 4. Валідація пристроїв перед записом (FR3.13)

- Перед початком запису перевірити наявність вибраних пристроїв відповідно до режиму виводу:
  - Режим "Мікрофон" — потрібен мікрофон
  - Режим "Loopback" — потрібен loopback-пристрій
  - Режим "Мікс" — потрібні обидва
- При відсутності пристрою — повідомити користувача (IPC-подія `recording-error` з кодом `DEVICE_NOT_FOUND`)
- Скрін-рідер озвучує повідомлення про помилку

---

## Технічні вимоги та обмеження

| Вимога | Деталі |
|--------|--------|
| Залежність | `rodio` + `symphonia` (OGG decoder) додається до `Cargo.toml` |
| Розмір | 3 OGG-файли ~10–30 КБ кожен, ~60–90 КБ додатково до .exe |
| Потоки | `rodio` створює окремий аудіо-потік для відтворення — не конфліктує з WASAPI-захопленням |
| Затримка звуку | Відтворення сповіщення не блокує зміну стану запису (асинхронне) |
| Конфлікти | Якщо гаряча клавіша конфліктує з іншою програмою — реєстрація провалюється, показати помилку |

---

## Definition of Done

- [ ] Натискання Pause/Break з будь-якого вікна Windows запускає/зупиняє/ставить на паузу запис
- [ ] Коротке натискання (< 500мс) в стані Recording → пауза
- [ ] Довге натискання (≥ 500мс) в стані Recording → зупинка
- [ ] Коротке натискання в стані Paused → відновлення
- [ ] Довге натискання в стані Paused → зупинка
- [ ] Будь-яке натискання в стані Idle → старт запису
- [ ] При старті запису чутний звуковий сигнал "старт"
- [ ] При паузі чутний звуковий сигнал "пауза"
- [ ] При зупинці чутний звуковий сигнал "стоп"
- [ ] Три звуки чітко розрізняються на слух
- [ ] Звуки вимикаються через налаштування
- [ ] Гаряча клавіша зберігається в `settings.json` та відновлюється при перезапуску
- [ ] Зміна комбінації клавіш набуває чинності без перезапуску
- [ ] Мнемоніки (Alt+літера) працюють для основних елементів UI
- [ ] При відсутності потрібного пристрою запис не починається, помилка озвучується скрін-рідером
