# AudioCaptor — Глосарій термінів

| Термін | Визначення |
|---|---|
| **Loopback** | Віртуальний аудіопристрій, що захоплює звук, який відтворюється через динаміки або навушники (системний звук). Дозволяє записувати те, що "чує" комп'ютер. |
| **WASAPI** | Windows Audio Session API — низькорівневий інтерфейс Windows для роботи з аудіопристроями. Забезпечує низьку затримку та високу якість захоплення звуку. |
| **Мікшування (mixing)** | Процес об'єднання кількох аудіопотоків (мікрофон + loopback) в один вихідний потік у реальному часі. |
| **Мікс (mix)** | Результат мікшування — аудіофайл, що містить об'єднаний звук з кількох джерел. |
| **Профіль запису (recording profile)** | Збережена конфігурація параметрів запису: пристрої, режим виводу, частота дискретизації, гучність, папка для збереження. |
| **Режим виводу файлів (file output mode)** | Визначає які файли створюються при записі: лише мікрофон, лише loopback, лише мікс, мікс + мікрофон, мікс + loopback. |
| **Частота дискретизації (sample rate)** | Кількість зразків аудіосигналу за секунду (Гц). Вищі значення забезпечують кращу якість. Підтримувані: 8000, 16000, 44100, 48000 Гц. |
| **Гучність (volume)** | Множник для аудіосигналу. Значення 1.0 — оригінальна гучність, >1.0 — підсилення, <1.0 — зменшення. Діапазон: 0.0–4.0. |
| **Clipping** | Обрізання аудіосигналу до допустимого діапазону [-1.0, 1.0] для запобігання спотворенням при підсиленні гучності. |
| **Гаряча клавіша (hotkey)** | Глобальна комбінація клавіш, що працює з будь-якого вікна Windows для керування записом. |
| **Коротке натискання (short press)** | Натискання гарячої клавіші тривалістю менше 500 мс. Використовується для старту, паузи та відновлення запису. |
| **Довге натискання (long press)** | Натискання гарячої клавіші тривалістю 500 мс або більше. Використовується для зупинки запису. |
| **Модифікатор (modifier)** | Клавіша-модифікатор (Ctrl, Alt, Shift), що натискається разом із основною гарячою клавішею для створення унікальної комбінації. |
| **Портативна програма (portable)** | Програма, що не потребує встановлення і зберігає всі дані (налаштування, записи, логи) поруч із виконуваним файлом. |
| **Scoop** | Пакетний менеджер для Windows, що дозволяє встановлювати та оновлювати програми з командного рядка. |
| **Persist (Scoop)** | Механізм Scoop для збереження користувацьких даних програми при оновленні. Файли та папки, вказані в маніфесті, не видаляються при оновленні версії. |
| **Зчитувач екрану (screen reader)** | Програма, що озвучує текст та елементи інтерфейсу для користувачів з порушеннями зору. Приклади: NVDA, JAWS. |
| **Мнемоніка (mnemonic)** | Підкреслена літера в назві елемента інтерфейсу, що дозволяє активувати його натисканням Alt + ця літера. |
| **WAV** | Формат аудіофайлу без стиснення (lossless). Забезпечує максимальну якість, але великий розмір файлу. |
| **Буфер (buffer)** | Тимчасова область пам'яті для зберігання аудіоданих між читанням з пристрою та записом у файл. |
| **Часова мітка (timestamp)** | Дата та час у форматі `YYYY-MM-DD_HH-MM-SS`, що автоматично додається до імені файлу запису. |
| **i18n** | Скорочення від "internationalization" (18 літер між i та n). Процес підготовки програми для підтримки кількох мов. |
| **Idle (очікування)** | Стан програми, коли запис не активний. Програма готова до початку нового запису. |
| **Recording (запис)** | Стан програми, коли активно записуються аудіодані у файл. |
| **Paused (пауза)** | Стан програми, коли запис призупинено. Аудіодані не записуються, але файл залишається відкритим для продовження. |
| **Базове ім'я файлу (base filename)** | Частина імені файлу запису без часової мітки. Наприклад, у файлі `mic_2026-03-28_14-30-00.wav` базове ім'я — `mic`. Користувач може задати власне базове ім'я для кожного типу файлу. |
| **Маніфест (manifest)** | Файл конфігурації пакета Scoop у форматі JSON, що описує як встановити, оновити та налаштувати persist для програми. |
| **Fallback** | Резервне значення, що використовується коли основне недоступне. Для мови: англійська використовується як fallback, якщо переклад відсутній. |
