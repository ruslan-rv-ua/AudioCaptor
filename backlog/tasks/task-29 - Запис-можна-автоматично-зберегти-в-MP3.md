## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
MP3 — найпоширеніший формат для обміну записами: на 128 кбіт/с файл у 12 разів менший за WAV (година — близько 58 МБ), і його відкриває будь-який програвач чи сервіс. Власник поставив MP3 другим форматом стиснення, після Opus (рішення decision-5).

Раніше MP3 чекав рішення про ліцензію: єдиний зрілий кодер, LAME, поширюється за LGPL, а AudioCaptor — один exe під MIT. Тепер кодувати можна вбудованим кодером Windows — MP3 Audio Encoder з Media Foundation, він є з Windows 8. Стороння бібліотека не потрібна, тож питання LGPL зникає. За пробною збіркою 26 листопада 2026 exe більшає приблизно на 5 КБ (LAME додав би ≈ 145 КБ), а пробний запис 48 кГц, стерео, 128 кбіт/с через Sink Writer вийшов правильним.

Що відомо про кодер із документації Microsoft:

- приймає лише 16-бітний цілочисельний PCM, моно або стерео;
- бітрейт — від 32 до 320 кбіт/с;
- частоти MPEG-1 — 32, 44,1 і 48 кГц; про нижчі частоти сторінки документації суперечать одна одній, тож профілі 8 і 16 кГц треба перевірити або перетворювати частоту;
- у N-версіях Windows кодера немає, доки не встановлено Media Feature Pack.

Спільну частину — вибір формату в профілі, кодування у фоні, тимчасовий файл, оголошення для скрінрідера — будує TASK-28 для Opus; тут додається кодер MP3.

У списку формату в профілі (рішення decision-6) MP3 має три варіанти: «MP3 — мовлення» (орієнтовно 64 кбіт/с: голос звучить так само, а година займає близько 29 МБ), «MP3 — стандарт» (128 кбіт/с) і «MP3 — висока якість» (орієнтовно 256–320 кбіт/с, для музики). Точні значення для мовлення й високої якості власник затверджує на слух.
