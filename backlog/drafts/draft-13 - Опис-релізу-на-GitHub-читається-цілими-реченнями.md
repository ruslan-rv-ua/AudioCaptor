## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Знайдено 2026-11-25 у робочій сесії TASK-10 (випуск 0.1.1).

Release бере опис релізу з розділу `CHANGELOG.md`, а рядки в `CHANGELOG.md` перенесено вручну, приблизно на 115 знаках. GitHub показує опис релізу так само, як коментарі: кожен перенос рядка стає розривом рядка. На сторінці https://github.com/ruslan-rv-ua/AudioCaptor/releases/tag/v0.1.1 вісімнадцять таких розривів посеред речень: кожен пункт розбито на 2–6 рядків. Зрячий читач бачить рвані рядки, а NVDA в режимі огляду читає пункт уривками: стрілка вниз зупиняється посеред речення.

Потрібне рішення власника, де виправляти:
- писати пункти `CHANGELOG.md` одним рядком, без ручних переносів (у редакторі файл читати менш зручно, зате він однаково виглядає всюди);
- або склеювати перенесені рядки пункту в `.github/workflows/release.yml`, коли той бере опис (файл лишається як є; зміну workflow перевіряють лише пробним запуском).

І окремо: чи виправити вручну опис уже опублікованого релізу v0.1.1 на GitHub. На exe, тег і маніфест Scoop це не впливає.
<!-- SECTION:DESCRIPTION:END -->
